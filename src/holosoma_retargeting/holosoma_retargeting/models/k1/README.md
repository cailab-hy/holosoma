# AI Sapiens K1 Rev.1 retargeting model

Generated by `scripts/build_k1_assets.py` from the upstream ROBOTIS `ai_sapiens_description`
package (Apache-2.0) and the omni-k1 `k1_retarget.xml` keypoint snapshot.

| File | Purpose |
| --- | --- |
| `k1_23dof.urdf` | Viser visualization (mesh paths relative to `meshes/`) |
| `k1_23dof.xml` | Retargeting model: robot-only tasks (`--robot k1`) |
| `k1_23dof_w_largebox.xml` | Retargeting model with the shared `models/largebox` object |

`k1_23dof.xml` contains, in addition to the physical links:

* `*_shoulder_roll_proxy`, `*_elbow_proxy`, `*_wrist_yaw_proxy`, `*_hip_roll_proxy`,
  `*_knee_proxy`, `*_ankle_roll_proxy`, `chest_torso_proxy` - keypoint frames used by the
  `(data_format, "k1")` joint mappings in `config_types/data_type.py`;
* `*_hand_tcp` - compact-hand tool center points (`L_Wrist` / `R_Wrist` targets);
* `*_foot_contact_{1..5}` - foot sticking markers (`RobotConfig.FOOT_STICKING_LINKS`) and
  `*_foot_front` toe targets;
* a ground plane.

The free joints are unnamed so the actuated-joint limit vector built by the retargeter has
the same layout as for G1/T1. The 23 hinge joints are in the same order as the holosoma
training model (`holosoma/data/robots/k1`).
